# Crawler

TypeScript crawler for collecting and transforming admission data.

## Requirements

- Node.js 18+
- npm 9+

## Setup

```bash
npm install
```

## Run

```bash
npm run crawl
```

From monorepo root you can also run:

```bash
npm run dev:crawler
```

## Notes

- Main entry: `src/index.ts`
- Output depends on current crawler scripts and settings.
